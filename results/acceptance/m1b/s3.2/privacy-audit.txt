== reviewer conclusion (manual review of the matches above)
- Section 4/5 matches are substring false positives: "port" in import/report/unreported/support, "ip" in local_ipc, "sin" in attach_since_mono_ns. No schema property, record field, manifest key or log line holds an address or a port.
- Stored BPF state (nkey, ncnt, nstash): only process key, class/syscall/destination-class codes, thread start time and u64 counters.
- User memory is read in exactly 3 places, all in net_dest(): sa_family (offset 0), the IPv4 address (offset 4, 4 bytes), the IPv6 address (offset 8, 16 bytes). The port (offset 2) and IPv6 flowinfo/scope are never read. The address bytes exist only in the locals a4/a6 of that function; only the computed class code (ND_*) leaves it.
- No kprobe, kretprobe, fentry/fexit or raw tracepoint: only TRACEPOINT_PROBE(syscalls, ...) and the existing sched tracepoints (test_net_unit.py::test_only_tracepoints_no_kprobes).
- Test inputs (tests/test_net_bpf.py V4/V6 lists) contain literal addresses as test data; the helper replies only fd, ret and errno; nothing records them.
